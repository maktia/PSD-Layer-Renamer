## なぜピクセルが劣化しないのか / 為什麼像素不會劣化 / Why pixels stay intact

一般的な PSD ライブラリはファイルを開くときに全レイヤーのピクセルを展開し、書き出すときに再圧縮します。この往復で半透明部分の色がわずかにずれ、テキストレイヤーやベクターレイヤーはラスタライズされます。

このツールは**レイヤーレコードだけを読み、ピクセルデータには一切触れません**。書き出しでは元ファイルのピクセル領域をそのままコピーするため、結果はバイト単位で元ファイルと同一になります。

> 一般的 PSD 函式庫在開檔時會把所有圖層的像素解壓縮，匯出時再重新壓縮。這趟來回會讓半透明部分產生細微色偏，文字與向量圖層也會被轉成點陣。這個工具**只讀圖層紀錄，完全不碰像素資料**，匯出時整塊照搬，結果逐位元與原檔相同。
